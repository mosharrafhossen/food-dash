# 🍔 FoodDash – Food Order Page

A modern, responsive food ordering web page built using **HTML, CSS, and JavaScript**.  
This project demonstrates a complete front-end food delivery experience including product listing, category filtering, cart system, and order confirmation.

🔗 **Live Demo:**  
👉 https://mosharrafhossen.github.io/food-order-page/

---

## ✨ Features

- 🛒 Add to Cart system with quantity control
- 📦 Dynamic product rendering using JavaScript
- 🗂️ Category-based filtering
- 🔍 Product details modal
- ✅ Order confirmation form
- 📱 Fully responsive (Mobile & Desktop)
- 🎨 Clean, modern UI design

---

## 🛠️ Technologies Used

- **HTML5** – Semantic structure
- **CSS3** – Flexbox, Grid, Responsive design
- **JavaScript (Vanilla)** – Dynamic UI & logic
- **Git & GitHub** – Version control
- **GitHub Pages** – Live hosting
